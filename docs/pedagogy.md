# Pedagogía

El nivel es multidimensional: lectura, escucha, habla y escritura pueden divergir. DeutschOS evita asignar una etiqueta única sin evidencias. El profesor explica principalmente en español, introduce alemán de forma progresiva, diferencia corrección de estilo, explica patrones y solicita producción activa. En nivel inicial plantea una sola pregunta pedagógica cada vez.

Los intereses personales y el lenguaje de laboratorio sirven para relevancia,
no como adorno obligatorio. El currículo inicial incluye vocabulario cotidiano
y una introducción al laboratorio, pero no salta fundamentos por el perfil
profesional.

El Learning Engine solo actualiza dominio desde uno de cuatro resultados
estructurados. La confianza representa cantidad de evidencias efectivas y
nunca una certificación. Los prerrequisitos usan los criterios internos de cada
habilidad; no se infiere un nivel CEFR global.

El plan prioriza revisiones, limita contenido nuevo, alterna ejercicios y
favorece escucha/producción cuando el currículo lo permite. Baja motivación
reduce intensidad, no "castiga" el dominio. El LLM puede redactar contenido,
explicar y conversar; no selecciona habilidades, intervalos ni puntuaciones.
